ℹ️ Sobre o Projeto

O Diamante Rastreador é uma plataforma gratuita e colaborativa para ajudar na localização de pessoas desaparecidas. Qualquer pessoa pode cadastrar uma ocorrência ou buscar informações.

📋 Regras de Uso

1. Cadastre apenas informações verídicas.
2. Não utilize a plataforma para fins ilegais.
3. Ao localizar a pessoa, marque como "Achado" imediatamente.
4. Os dados são armazenados de forma segura.
5. Em caso de emergência, ligue 190.
